# GitHub User Search App

A sleek and responsive GitHub user search application built with React and Tailwind CSS.

## Live Demo
<a href="https://github-user-search-app-rho-ten.vercel.app/">Demo</a>

## Features

- Search any GitHub user by username
- View profile picture, name, and bio
- See public repositories, followers, and following count
- Direct link to GitHub profile
- Error handling for invalid usernames
- Clean and responsive dark UI

## What I Learned

While building this project, I deeply studied and applied the following concepts:

**Async Programming**
- How JavaScript Event Loop works internally
- Call Stack, Web APIs, Microtask and Macrotask Queue
- Why Callback Hell was a problem and how Promise solved it
- How async/await makes asynchronous code readable

**React**
- Managing state with useState
- Fetching data with async/await inside React components
- Handling loading and error states
- Semantic HTML inside JSX

**API Integration**
- Working with GitHub REST API
- Using response.ok to handle HTTP status codes
- Parsing JSON responses with response.json()

## Tech Stack

- React
- Tailwind CSS
- GitHub REST API
